# Glossary

## Internal Terms
- **API Bridge:** Refers to the `background.js` Service Worker, which acts as a proxy to make cross-origin requests that Content Scripts cannot make.
- **Shadow Panel / Floating Bar:** The `.cx-floating-bar` UI injected into the Automoby dashboard by `content.js`.
- **Sloppy JSON:** Refers to the malformed, non-standard JavaScript object literal strings generated by Chapar's PHP backend (lacking quotes around keys, containing illegal escapes).
- **DNR:** `declarativeNetRequest`, a Chrome API used to spoof HTTP headers.

## External Services
- **Automoby (`panel.automoby.ir`):** The internal CRM dashboard where the extension operates.
- **Chapar (`portal.chaparnet.com`, `app.krch.ir`):** A third-party logistics company.
- **Iran Post (`tracking.post.ir`):** The national postal service of Iran.

## Chrome Extension Terms
- **MV3:** Manifest Version 3, the current architecture standard for Chrome Extensions.
- **Service Worker:** The background script environment in MV3 (`background.js`).
- **Content Script:** Javascript injected directly into web pages (`content.js`, `ui-render.js`, `iran-post.js`).
